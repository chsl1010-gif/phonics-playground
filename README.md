# 파닉스 놀이터

그림과 소리로 영어 글자의 소리(파닉스)를 익히는 어린이용 놀이예요.

**바로 하기: https://phonics-playground-jade.vercel.app**

## 놀이 방법

- **첫소리 찾기**: 그림을 보고 단어의 첫 글자를 4개 중에서 골라요.
- **귀 쫑긋**: 그림을 가린 채 영어 단어를 듣고 첫소리 글자를 골라요.
- **단어 만들기**: c-a-t처럼 글자를 순서대로 눌러 세 글자 단어를 만들어요.
- 맞히면 별을 받고, 5개 연속으로 맞히면 칭찬 배너가 나와요.
- 모음(a e i o u)은 빨강, 자음은 파랑으로 보여 줘요.

## 아이별 기록

- 위쪽 "누가 놀이하나요?"에서 아이를 추가하고 골라요. 이름과 동물 아이콘을 정할 수 있어요.
- 별, 정답률, 알파벳별 익힘 정도가 아이마다 따로 저장돼요.
- 많이 틀린 글자는 문제에 더 자주 나와요.
- 기록은 그 기기의 브라우저에 저장돼요. 다른 기기에서 열면 기록이 이어지지 않아요.

## 만들기

`index.html` 파일 하나로 되어 있어요. `main` 브랜치에 올리면 Vercel이 자동으로 배포해요. 영어 소리는 브라우저의 읽어 주기 기능을 써서, 기기마다 목소리가 달라요.
